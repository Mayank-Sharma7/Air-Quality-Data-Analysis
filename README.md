# Air Quality Data Analysis Using Python

## 1. Introduction
This project analyzes air-quality data using Python.
It explores pollution measurements and identifies patterns
using data cleaning, statistical analysis, and visualization.

## 2. Objectives
- Analyze air-quality data.
- Handle missing values and duplicate records.
- Calculate pollutant averages and medians.
- Compare air-quality measurements across cities.
- Generate graphs and visualizations.
- Study correlations between pollutants.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 4. Project Files
- `air_quality_analysis.py` - Python source code.
- `Air_Quality_Data_Analysis_Case_Study.pdf` - Project report.
- `README.md` - Project documentation.

## 5. Main Analysis
- Dataset inspection and cleaning
- Missing-value analysis
- Duplicate-record detection
- City-wise pollutant analysis
- PM2.5 and PM10 comparison
- Pollutant correlation analysis
- Data visualization

## 6. Visualizations
The program is designed to generate:
- PM2.5 levels by city
- PM2.5 distribution histogram
- Pollutant correlation heatmap
- PM2.5 versus PM10 scatter plot
- PM2.5 time-series line chart
- City distribution pie chart
- Box plot and violin plot
- City observation count plot
- Pair plot

## 7. Libraries Required
Install the required libraries using:

`pip install pandas numpy matplotlib seaborn`

## 8. Execution
Run the Python program using:

`python air_quality_analysis.py`

Note: The dataset must be available at the file path
specified in the Python code.

## 9. Conclusion
This project demonstrates how Python libraries can be
used to clean, analyze, summarize, and visualize air-quality
data. The findings depend on the dataset used.
